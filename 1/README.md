# 会员管理系统 - 部署指南

## 🚀 一键部署到 Vercel（推荐）

### 方法1：通过 Vercel CLI（最简单）

1. 安装 Vercel CLI
```bash
npm install -g vercel
```

2. 在项目目录运行
```bash
vercel
```

3. 按照提示操作：
   - 登录 Vercel 账号
   - 选择项目设置（直接回车使用默认）
   - 等待部署完成

4. 获取部署链接，例如：`https://your-project.vercel.app`

### 方法2：通过 Vercel 网站（无需命令行）

1. 将此文件夹压缩成 ZIP
2. 访问 https://vercel.com
3. 注册/登录账号（可以用 GitHub/Google 登录）
4. 点击 "Add New" → "Project"
5. 点击 "Upload" 上传 ZIP 文件
6. 点击 "Deploy" 等待部署完成
7. 获取网址

## 🎯 使用说明

### 数据存储
- 数据存储在云端（window.storage）
- 自动同步，团队共享
- 如果云端失败，自动备份到浏览器本地

### 升级订单
```
示例：02昨天升级跟圈号年卡70
系统会自动查找该客户的历史订单，只记录补差价70元
```

### 续费订单
```
示例：03今天续费素材群季卡
系统会自动检测原套餐剩余时长，从到期日开始续费
```
